# 破甲频道推广手册

给 Telegram 频道 [t.me/LLM_PoJia](https://t.me/LLM_PoJia) 用的落地文档。

频道帖本身不能加密。完整内容和密码只放在**机器人私聊**里发。不要做「转发到多个群才给密码」：Telegram 查不到用户有没有转到别人的群，也容易被当成刷广告封号。

| [02-方案B-邀请解锁.md](02-方案B-邀请解锁.md) | 邀请好友后领取合集：流程图、规则、防刷 |

## 建议顺序

1. 先做方案 A，用第二个账号测通「未关注不发、已关注才发」。
2. 跑一周，看领取率和取关率。
3. 再打开方案 B：关注得本期，邀请 2 人得往期合集。

不要把所有内容都锁在邀请后面。
